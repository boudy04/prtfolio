# Portfolio Site — Project #1

Static, zero-build personal site for Abdelrahman Magdy. Hosted free on GitHub Pages.

## Run locally
Open `index.html` in a browser. No install, no build step.

## Deploy (GitHub Pages)
1. Create repo `prtfolio` under `github.com/abdelrahmanmagdy`.
2. Push this folder: `git add index.html README.md && git commit -m "portfolio" && git push`.
3. Repo → Settings → Pages → Source: `main` branch, `/ (root)` → Save.
4. Live at `https://abdelrahmanmagdy.github.io/prtfolio/`.
